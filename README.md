# Discord-Server-Repoter-God-x-Father-
GOD × FATHER — Discord Reporter Tool. A lightweight Windows application with a clean, user-friendly interface and a simple reporting workflow. Easy to download, install, and use. Built to assist users with responsible reporting through Discord's official reporting process. Unofficial community project.

Welcome to GOD × FATHER – Discord Reporter Tool.

This repository contains the initial project files, including the Python application and supporting configuration files.

Project Files:
• Reporter.py – Main Python application.
• tokens.txt – Local configuration file (never publish account tokens).
• Leverages.log – Application log file.

Project Goals:
• Simple and user-friendly interface.
• Organized project structure.
• Lightweight Windows application.
• Easy setup and installation.
• Responsible reporting through official Discord channels.

This is an unofficial community project and is not affiliated with Discord.
